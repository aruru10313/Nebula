1. Nebula 이용

Nebula는 현실경제 Minecraft 서버와 호환 클라이언트 파일에 접근하고 관리하기 위해 제공됩니다. 소프트웨어를 설치하고 실행할 권한이 있는 기기에서만 Launcher를 사용하세요.

2. 외부 서비스

Nebula는 Microsoft 인증, Modrinth, GitHub Releases 및 Nebula 배포 서버에 의존합니다. 해당 서비스는 각각의 약관과 운영 정책을 따르며, Nebula는 외부 서비스의 가용성이나 콘텐츠를 보장하지 않습니다.

3. 모드 및 파일

Minecraft 1.20.1 및 Forge 47.4.23과 호환되고 신뢰할 수 있는 모드만 설치하세요. 개인 옵션 모드는 서버 필수 파일과 분리되어 있지만 호환성 확인은 사용자의 책임입니다.

4. 면책

Nebula는 현재 상태로 제공됩니다. 월드와 중요한 파일은 별도로 백업하세요. 오용, 호환되지 않는 외부 파일 또는 제작자가 통제할 수 없는 서비스 중단으로 인한 데이터 손실에 대해 제작자는 책임을 지지 않습니다.
