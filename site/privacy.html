개인정보처리방침

최종 수정일: 2026년 9월 14일

1. 개요

Nebula는 aruru가 현실경제 서버를 위해 제작한 커뮤니티 Minecraft 런처입니다. 이 방침은 런처와 웹사이트가 처리하는 정보를 설명합니다.

2. 처리하는 정보

런처는 계정 토큰, 선택한 설정, 게임 파일, 로그 및 개인 옵션 모드 정보를 사용자의 기기에 로컬로 저장합니다. Microsoft 인증은 Microsoft 서비스를 통해 처리되며 Nebula는 Microsoft 비밀번호를 받거나 저장하지 않습니다.

웹사이트는 정적 다운로드 페이지이며 광고 추적기, 분석 쿠키 또는 별도 회원 계정을 사용하지 않습니다. GitHub와 호스팅 제공자는 자체 정책에 따라 IP 주소와 요청 시간 등 기본 접속 정보를 처리할 수 있습니다.

3. 모드 및 업데이트 서비스

개인 모드 브라우저를 이용하면 Modrinth에서 공개 프로젝트 및 파일 정보를 요청합니다. 런처 업데이트는 GitHub Releases에서 제공하며, 서버 필수 파일은 Nebula 배포 서버에서 제공합니다.

4. 정보 관리

운영체제 또는 런처 설정을 통해 기기에 저장된 런처 데이터, 계정, 로그 및 개인 옵션 모드를 삭제할 수 있습니다. 런처 데이터 폴더와 인증 파일을 다른 사람과 공유하지 마세요.

5. 문의
