Privacy Policy

Last updated: September 14, 2026

1. Overview

Nebula is a community Minecraft launcher created by aruru for the 현실경제 server. This policy explains what information the launcher and this website handle.

2. Information we handle

The launcher stores account tokens, selected settings, game files, logs, and personal option-mod metadata locally on your device. Microsoft authentication is handled through Microsoft's services; Nebula does not receive or store your Microsoft password.

The website is a static download page. It does not use advertising trackers, analytics cookies, or user accounts. GitHub and the hosting provider may process standard connection data such as IP address and request time according to their own policies.

3. Mod and update services

When you use the personal mod browser, the launcher requests public project and file information from Modrinth. Launcher updates are served through GitHub Releases. Required server files are served from the Nebula distribution server.

4. Data control

You can remove locally stored launcher data, accounts, logs, and personal option mods through your operating system or the launcher settings. Do not share your launcher data directory or authentication files with others.

5. Contact

For privacy questions, contact aruru.
