# Nebula Launcher notices

Nebula Launcher is a custom launcher for the 현실경제 Minecraft server. It is
based on [HeliosLauncher](https://github.com/dscalzi/HeliosLauncher) by Daniel
D. Scalzi and uses Helios Core/distribution components.

Nebula-specific work includes the launcher UI, fixed Minecraft 1.20.1 / Forge
47.4.23 configuration, Microsoft authentication integration, distribution
hosting, automatic Java and mod management, download verification, and the
server news integration.

The original MIT license and copyright notice are preserved in `LICENSE.txt`.
Third-party dependencies and bundled components remain subject to their own
licenses. Nebula branding and server content are not part of the upstream
HeliosLauncher project.
